# Changelog

## 1.0.0 — proposed first release

- Shared single page converter for web and CLI, with article/full page and front matter options.
- Bounded browser readiness and resources, public URL checks through redirects and subrequests, and clearer errors.
- Editable Markdown, escaped preview, copy/save controls, responsive and accessible UI improvements.
- Local fixtures, API and UI tests, CI, screenshot, and contributor/security documentation.

The release is proposed; no tag or public release has been created.
